■ خلاصه
- موضوع: نمایشگاه مجازی آثار طراحی لباس
- تعداد آثار: حدود ۱۰۰ عدد
- حرکت: اول‌شخص (WASD + ماوس)
- رای‌گیری: با کلید E روی هر اثر
- فناوری: Three.js 0.160 — تک فایل HTML
- میزبانی: Vercel / Netlify / GitHub Pages (رایگان)

■ کلیدها
W/S/A/D یا جهت‌دار : حرکت
Shift             : دویدن
ماوس              : چرخش دوربین
E یا کلیک         : رای دادن
Esc               : خروج

■ نصب
۱. پوشه‌ای بسازید و فایل index.html را داخلش بگذارید.
۲. با دوبار کلیک بازش کنید.
۳. برای تست پیشرفته: python -m http.server 8000
   سپس http://localhost:8000

■ عکس‌های واقعی
پوشه works/ بسازید و عکس‌ها را (با عرض ۸۰۰px و حجم زیر ۱۵۰KB)
داخل آن بگذارید. در بخش WORKS کد:

const WORKS = [
  { id: 1, title: 'کت‌وشلوار پاییزه', image: 'works/01.jpg' },
  { id: 2, title: 'لباس شب مخمل',      image: 'works/02.jpg' },
  // ...
];

■ تنظیمات مهم (در CFG)
HX / HZ      : ابعاد سالن (پیش‌فرض 28 و 14)
HEIGHT       : ارتفاع سقف (5.5)
WALK / RUN   : سرعت راه رفتن / دویدن (4.2 / 7.5)
FRAME_W/H    : ابعاد قاب (1.8 × 2.6)
FRAME_Y      : ارتفاع قاب (2.2)

■ عیب‌یابی
صفحه سفید       : CDN بلاک است → three.module.js را لوکال کنید
موس نمی‌چرخد     : دوباره کلیک کنید (Pointer Lock)
FPS پایین        : تعداد PointLight را کم کنید
رای ذخیره نمی‌شود : localStorage مسدود است
تصویر لود نمی‌شود : از http://localhost استفاده کنید

■ استقرار
Vercel  : vercel.com → ثبت‌نام → drag & drop پوشه
Netlify : netlify.com/drop → پوشه را رها کنید
GitHub Pages : push به مخزن → Settings → Pages → main

■ مرحله بعدی (نسخه واقعی با IP)
- Serverless Function در /api/vote
- Upstash Redis یا Cloudflare KV
- کلید vote:{workId}:{ipHash} با TTL ۳۰ روزه
- میزبانی: Cloudflare Workers (پایدارتر در ایران)

■ نکته مهم
در نسخه فعلی، رای‌ها در localStorage ذخیره می‌شوند (فقط تست).
برای مسدودسازی واقعی IP، بک‌اند لازم است.
